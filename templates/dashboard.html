🤖 AI Risk Scoring Layer

Use our advanced AI model to assess and score security risks based on vulnerability data, asset criticality, and threat intelligence.

The AI Risk Scoring component is a core feature of VigiScan+, responsible for transforming raw vulnerability data into prioritized, actionable intelligence. Instead of relying solely on static severity ratings, the system applies intelligent models to evaluate vulnerabilities within a broader operational and threat context.

The scoring mechanism incorporates multiple critical factors:

  • CVSS Severity Levels:
    The system utilizes standardized severity ratings from the Common Vulnerability Scoring System (CVSS) as a baseline indicator of vulnerability impact. These scores provide an initial measure of how severe a vulnerability is in terms of confidentiality, integrity, and availability.
  • Exploit Availability:
    The AI model considers whether exploit code is publicly available or actively used in the wild. Vulnerabilities with known exploits are assigned higher priority due to their increased likelihood of being targeted.
  • Asset Criticality:
    Not all assets carry the same level of importance. The system evaluates the business value and sensitivity of affected assets (e.g., databases, authentication servers, critical infrastructure) to determine the potential impact of exploitation.
  • Threat Intelligence Feeds:
    External threat intelligence sources are incorporated to provide real-time context on emerging threats, attack trends, and adversary behavior. This enhances the system’s ability to prioritize vulnerabilities based on current risk landscapes.

Using these inputs, the AI model generates a dynamic risk score, which is then used to classify vulnerabilities into three primary categories:

  • High Priority – Requires immediate attention due to critical impact and high exploitability
  • Medium Priority – Important but not immediately critical; requires scheduled remediation
  • Low Priority – Minimal risk; can be addressed during routine maintenance

This intelligent prioritization ensures that security teams focus their efforts on the most dangerous vulnerabilities first, thereby optimizing resource allocation and improving overall security posture.

Getting Started

VigiScan is a comprehensive vulnerability scanning platform designed to help security teams identify and manage vulnerabilities in their infrastructure.

Main Features

  • Start Scan: Launch a new vulnerability scan against a target
  • Asset Inventory: Manage and track your organization's assets
  • Vulnerability Tracker: Track vulnerabilities across your assets
  • AI Risk Scoring: Use AI-powered risk assessment for vulnerabilities
  • Knowledge Base: Access security best practices and remediation guides
  • Scan History: Review past scan results and trends

Scan Profiles

  • Deep Scan: Complete assessment with Nmap, ZAP Spider, and Active Scanning
  • Quick Scan: Fast assessment with Nmap and ZAP Spider
  • Targeted - Ports Only: Network port enumeration only
  • Targeted - Web Only: Web application scanning only

Vulnerability Management

Use the Vulnerability Tracker to:

  • View all discovered vulnerabilities
  • Update vulnerability status (Open, In Progress, Resolved, Accepted Risk)
  • Track remediation efforts
  • Monitor compliance requirements

Best Practices

  • Schedule regular scans for continuous monitoring
  • Keep asset inventory up to date
  • Address high-risk vulnerabilities first
  • Use the Knowledge Base for remediation guidance
