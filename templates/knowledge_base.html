VigiScan is a vulnerability scanning tool that identifies security weaknesses in web applications and network targets. It helps users detect, prioritize, and understand vulnerabilities, and provides actionable recommendations for remediation.
1. Enter a Target URL or IP address Example: https://example.com or 192.168.1.1 2. Select a Scan Type: Web Scan → scans web applications IP Scan → checks open ports and services Full Scan → combines both 3. Click Start Scan
Web Scan Scans web applications for vulnerabilities like XSS, SQL Injection, etc. IP Scan Identifies open ports and services on a network target. Full Scan Performs both IP and web scanning for deeper analysis.
High (🔴) → Critical vulnerabilities, fix immediately Medium (🟠) → Moderate risk, fix soon Low (🟢) → Minor issues Each result includes: • Vulnerability name • Affected URL or port • Description • Recommended fix
• Only scan systems you own or have permission to test • Scans may take a few minutes depending on target size • Results may require manual verification 👉 This is important for your defense—shows awareness of ethics.
Tips for Best Results • Use Full Scan for deeper analysis • Ensure target is reachable • For better accuracy, scan authenticated areas (if supported)
Troubleshooting Common Errors • Invalid URL/IP → Check format • Scan not starting → Ensure backend is running • No results → Target may not have detectable vulnerabilities
